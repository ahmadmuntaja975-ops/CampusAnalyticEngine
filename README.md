# Campus Analytics Engine

Campus Analytics Engine is a C++ console-based project developed for managing university/campus records.

## Features
- Student Management
  - Add Student
  - Search Student
  - Update Student
  - Delete Student

- Course Management
- Attendance Management
- Grade Management
- Fee Tracking
- Reports Generation
